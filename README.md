I'm Paweł, an AI engineer in Przemyśl, Poland. I run [Applied AI](https://appliedai.dev) with my brother Piotr. Most of our code sits in private repositories; the products are listed first, the public code after.

**What I'm building**

- [CityChat](https://citychat.pl): a city guide you talk to: sights, food, events and local services, landmark search with the camera, and a map built for wandering. Live in 25 cities across Europe. [App Store](https://apps.apple.com/app/id6793043983) · [Google Play](https://play.google.com/store/apps/details?id=pl.citychat.android)
- [SanAlert](https://sanalert.pl): unofficial early warning about air threats over Poland: drones and missiles tracked across the border, a threat level for the place you choose, and official RCB and RSO messages in their original wording. On the web, iPhone, Mac, Apple Watch, Android and Wear OS. [App Store](https://apps.apple.com/pl/app/sanalert/id6814808880) · [Google Play](https://play.google.com/store/apps/details?id=dev.appliedai.sanalert)
- [FormFlow](https://formflow.solutions): contact forms that consumer brands run without developers: drafts and publishing, the form version kept with every submission, routing by brand and topic, on the brand's own domain or embedded. Because every submission comes through the form, every attached photo gets checked for authenticity. With Piotr; in deployment.
- [Składki](https://skladki.edu.pl): fees and collections without a spreadsheet, for paid classes and for school and kindergarten groups. The money never passes through Składki: online payments go straight to the instructor's own Stripe account.
- [Kluster](https://getkluster.app): a native macOS client for Kubernetes: a window per cluster, tables that update from watch streams instead of polling, and the whole API including CRDs. SwiftUI, no Electron. Piotr's app; I'm a co-author.
- A 6-node k3s cluster across home and office, with a GPU workstation serving self-hosted LLMs, embeddings, speech-to-text and OCR.

- [agent-skills](https://github.com/plrojek/agent-skills): my Claude Code plugins: App Store header videos that work on an iPhone, transcripts with named speakers from noisy recordings, Polish genealogy record search, a 3D view of a planting plan, SanAlert for AI assistants, and a guard for agent sessions that execute a plan.

- [polish-law-checker](https://github.com/appliedai-pl/polish-law-checker): checks the Polish-law citations in a document against the official text. With Piotr, at [Applied AI](https://github.com/appliedai-pl).
